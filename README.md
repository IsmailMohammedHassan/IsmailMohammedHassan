# 💫 About Me

I'm a Front-End Developer with 4+ years of experience building modern, data-intensive web applications using React.js and Next.js.

I specialize in building scalable user interfaces, reusable component architectures, and high-performance applications. My experience includes real-time blockchain analytics at TapTools, cybersecurity dashboards at Femto Security, and AI-powered web applications and automation dashboards at ToolTech, where I work as Co-Founder & Front-End Lead.

I'm passionate about performance optimization, data visualization, secure front-end development, and creating smooth user experiences for complex applications.

Alongside my development work, I teach front-end development and React.js as a part-time instructor at the Information Technology Institute (ITI), helping students understand core concepts and build practical applications.

- 🔭 **Currently working on:** AI-powered applications and automation dashboards at ToolTech.
- 💻 **Main Stack:** React.js, Next.js, JavaScript, and Redux.
- ⚡ **Specialties:** Performance optimization, reusable components, virtualization, and code splitting.
- 🔐 **Security:** XSS prevention, Content Security Policy (CSP), and secure data handling.
- 📊 **Experience:** Blockchain analytics, cybersecurity dashboards, and data-intensive interfaces.
- 🎓 **Teaching:** Front-End Development and React.js at ITI.
- 🌍 **Location:** Egypt | Open to Remote Opportunities.
